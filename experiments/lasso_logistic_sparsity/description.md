# Lasso Logistic Sparsity

Compares sparsity and prediction tradeoffs for lasso logistic regression using custom nonsmooth solvers and sklearn's L1 `saga` baseline.

Outputs are written to `results/runs.csv`, `results/iterations.csv`, `results/metadata.json`, and `results/summary.csv`.

## How to run

From the repository root:

```bash
python experiments/lasso_logistic_sparsity/code/run.py
```

The run writes raw CSV files and creates `results/summary.csv` automatically.

Useful options:

```bash
python experiments/lasso_logistic_sparsity/code/run.py --dry-run
python experiments/lasso_logistic_sparsity/code/run.py --limit-runs 10
python experiments/lasso_logistic_sparsity/code/run.py --output-dir /tmp/lasso_results
```

## How to change parameters

Edit `code/config.py`. The experiment matrix is built in `build_configs()`.

Important fields:

- `dataset`: CSV files under `data/`, or absolute paths if added manually.
- `lambda`: L1 penalty coefficient used by the custom objective and sklearn baseline.
- `seed` and `test_size`: train/test split controls.
- `D`, `gamma_mult`, `alpha`, `max_iter`, `eps`: solver controls.
- `method`: SDA variants, projected subgradient, or `sklearn_saga`.

Main report metrics are test accuracy, test loss, runtime, and `nonzero_count`.

Configured datasets are `iris.csv`, four synthetic logistic datasets generated by
`data/generate_logistic_data.py`, and three normalized UCI datasets:
`breast_cancer_wdbc.csv`, `banknote_authentication.csv`, and `spambase.csv`.
